API REST para Livraria

Este projeto é uma API RESTful desenvolvida em JavaScript, que utiliza MongoDB como banco de dados para armazenar informações da nossa livraria.

Tecnologias utilizadas

- JavaScript (Node.js / Express)

- MongoDB (banco de dados NoSQL)

- Mongoose (ODM para MongoDB)

Descrição

A API permite o gerenciamento eficiente do catálogo de livros, possibilitando operações CRUD (Criar, Ler, Atualizar, Deletar) sobre os dados da livraria.

Funcionalidades

- Cadastro e atualização de livros

- Consultas por autor, título e outros filtros

- Exclusão de registros

- Integração com banco NoSQL para escalabilidade e flexibilidade dos dados
